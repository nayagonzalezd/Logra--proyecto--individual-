## LOGRA — Gestor de tareas
Organiza tus ideas. Cumple tus metas

**LOGRA** 
Es una aplicación web diseñada para organizar tareas, administrar pendientes y hacer seguimiento al progreso de las actividades de manera sencilla y mas práctica.

## Objetivo
Facilitar la planificación y organización de las tareas diarias mediante una interfaz clara y fácil de usar.

## Tecnologías
- HTML
- CSS
- JavaScript
- Bootstrap

## Funcionalidades proyectadas
- Crear tareas.
- Consultar tareas pendientes.
- Organizar tareas por estado.
- Marcar tareas como completadas.
